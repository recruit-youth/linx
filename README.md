# LINX株式会社 コーポレートサイト

テクノロジーとデザインでビジネスをつなぐ、LINX株式会社のコーポレートウェブサイトです。

---

## 📁 プロジェクト構成

```
/
├── index.html          # メインページ（全セクション）
├── css/
│   └── style.css       # メインスタイルシート（レスポンシブ対応）
├── js/
│   └── main.js         # メインJavaScript（インタラクション・アニメーション）
└── README.md
```

---

## ✅ 実装済みの機能

### ページ構成（シングルページ）
| セクション | ID | 説明 |
|---|---|---|
| ヘッダー | `#site-header` | 固定ヘッダー、スクロール検知でスタイル変化 |
| ヒーロー | `#hero` | フルスクリーンヒーローセクション |
| 数値実績 | ― | カウントアップアニメーション付き数字表示 |
| About | `#about` | 会社概要・特徴 |
| Service | `#service` | 6サービス カードグリッド |
| Works | `#works` | 実績カード（カテゴリフィルタリング機能付き） |
| CTA | ― | 問い合わせ誘導バナー |
| News | `#news` | ニュース一覧 |
| Contact | `#contact` | お問い合わせフォーム（バリデーション付き） |
| フッター | ― | サイトマップ・著作権表示 |

### インタラクション
- **ヘッダー**: スクロールに応じた背景・テキスト色変化
- **ハンバーガーメニュー**: モバイル用ドロワーナビゲーション
- **スムーススクロール**: アンカーリンクによるセクション移動
- **スクロールトップボタン**: 右下に表示、クリックでトップへ
- **AOS（独自実装）**: スクロールトリガーのフェードインアニメーション
- **数値カウンター**: ビューポート侵入時のカウントアップ
- **Worksフィルター**: カテゴリ別絞り込み（all / web / app / dx / ai）
- **フォームバリデーション**: リアルタイム・送信時バリデーション + 送信完了表示
- **アクティブナビ**: スクロール位置に応じたナビゲーションハイライト

## 🌐 使用技術・ライブラリ

| 技術 | 用途 |
|---|---|
| HTML5 | セマンティックマークアップ |
| CSS3（カスタムプロパティ） | スタイリング・レスポンシブ |
| Vanilla JavaScript | インタラクション・アニメーション |
| Google Fonts (Inter / Noto Sans JP) | タイポグラフィ |
| Font Awesome 6 | アイコン |

> ※ 外部フレームワーク（React, Vue等）は使用していません。
> ※ CDNはGoogle FontsおよびFont Awesome (jsDelivr) のみ使用。

## 📱 レスポンシブ対応

| ブレークポイント | 対応内容 |
|---|---|
| `> 1024px` | フルレイアウト（3カラムグリッド） |
| `≤ 1024px` | 2カラムグリッド、フッター2列 |
| `≤ 768px` | 1カラム、ハンバーガーメニュー表示 |
| `≤ 480px` | スタック表示、ボタン全幅 |
